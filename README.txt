# Interactive Timeline with Artifacts – Indian Art History

## How to run
1. Extract this ZIP folder.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Use Live Server in VS Code, or double-click `index.html`.

## Features
- Interactive historical timeline
- 7 artifacts/periods
- Clickable artifact cards with detailed pop-ups
- Artifact gallery with period filters
- Responsive design
- Built-in vector illustrations, so the artifact visuals work without separate image files or internet access

## Suggested viva explanation
"This project is an interactive educational timeline that presents major stages of Indian art history. Users can navigate the timeline, filter the artifact gallery and click an artifact to view its period, place, material, description and historical context."

## References used for factual grounding
- National Museum, New Delhi – Dancing Girl and Buddha Head
- Museums of India / National Museum – Nataraja
- Archaeological Museum, Sarnath – Lion Capital of Ashoka
